# LocalSignage Cloud Android V2.3.1 Stable

- Token de pairing persistant: pas de code à redemander après fermeture/redémarrage.
- Heartbeat en service foreground toutes les 20 s.
- Ecran maintenu actif avec FLAG_KEEP_SCREEN_ON.
- Cache local des vidéos/images, lecture hors ligne et cache de la dernière configuration.
- Assignment Playlist / Média / Live.
- Fit / Fill / Étiré / Zoom.
- Auto / Landscape / Portrait.
- HLS et RTSP via Media3; RTMP/SRT nécessitent un gateway.
